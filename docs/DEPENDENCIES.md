# 项目依赖说明

本文档说明项目中使用的主要依赖包及其用途。

## 核心依赖

### 深度学习框架

#### `torch` 和 `torchvision`
- **用途**：PyTorch 深度学习框架
- **在项目中的作用**：
  - 构建和训练神经网络模型（感知、决策、控制）
  - 处理图像数据（路口场景识别）
  - 实现端到端的自动驾驶模型
- **为什么选择 PyTorch**：动态图、易于调试、社区活跃、适合研究

### 计算机视觉

#### `opencv-python`
- **用途**：OpenCV 计算机视觉库
- **在项目中的作用**：
  - 图像预处理（去噪、增强、变换）
  - 特征提取（边缘检测、角点检测）
  - 目标检测和跟踪（车辆、行人、障碍物）
  - 相机标定和图像校正
  - 视频处理和实时可视化

#### `pillow` (PIL)
- **用途**：Python 图像处理库
- **在项目中的作用**：
  - 图像格式转换
  - 图像尺寸调整和裁剪
  - 图像增强和滤镜

### 数值计算和数据处理

#### `numpy`
- **用途**：数值计算基础库
- **在项目中的作用**：
  - 数组操作和矩阵运算
  - 数值计算（距离、角度、速度计算）
  - 数据格式转换
  - 与 PyTorch 数据交互

#### `pandas`
- **用途**：数据处理和分析
- **在项目中的作用**：
  - 训练数据管理（CSV、JSON 格式）
  - 数据清洗和预处理
  - 实验结果的记录和分析
  - 数据集统计和可视化

#### `scipy`
- **用途**：科学计算库
- **在项目中的作用**：
  - 信号处理（传感器数据滤波）
  - 优化算法（路径规划优化）
  - 统计分析（性能评估）

### 可视化

#### `matplotlib`
- **用途**：基础绘图库
- **在项目中的作用**：
  - 训练曲线绘制（loss、reward）
  - 数据分布可视化
  - 静态图表生成
  - 结果报告生成

#### `plotly`
- **用途**：交互式可视化库
- **在项目中的作用**：
  - **3D 场景可视化**（路口场景、车辆轨迹）
  - 交互式训练监控面板
  - 实时数据可视化
  - Web 端可视化展示

#### `seaborn`
- **用途**：统计可视化库
- **在项目中的作用**：
  - 数据分布分析
  - 相关性分析
  - 美观的统计图表

### 强化学习

#### `gymnasium`
- **用途**：强化学习环境标准接口
- **在项目中的作用**：
  - 创建无红绿灯路口驾驶环境
  - 定义状态空间、动作空间、奖励函数
  - 环境交互接口（step, reset）
  - 环境渲染和可视化

#### `stable-baselines3`
- **用途**：强化学习算法实现库
- **在项目中的作用**：
  - 实现 PPO、SAC、TD3 等算法
  - 训练自动驾驶决策模型
  - 模型保存和加载
  - 超参数调优

### 训练监控

#### `tensorboard`
- **用途**：TensorFlow 的可视化工具（也支持 PyTorch）
- **在项目中的作用**：
  - 实时监控训练过程
  - 可视化损失函数、奖励曲线
  - 模型结构可视化
  - 超参数对比

#### `wandb` (可选但推荐)
- **用途**：Weights & Biases 实验跟踪平台
- **在项目中的作用**：
  - 云端实验管理
  - 超参数搜索
  - 模型版本管理
  - 团队协作和结果分享

### 工具库

#### `pyyaml`
- **用途**：YAML 配置文件解析
- **在项目中的作用**：
  - 模型配置管理（超参数、网络结构）
  - 训练配置（学习率、批次大小等）
  - 环境配置（路口参数、车辆参数）

#### `tqdm`
- **用途**：进度条显示
- **在项目中的作用**：
  - 训练进度显示
  - 数据处理进度
  - 提升用户体验

## 开发依赖

- **`black`**：代码格式化工具
- **`flake8`**：代码风格检查
- **`mypy`**：静态类型检查

## 依赖管理

项目使用 `uv` 管理依赖，确保：
- ✅ 快速安装（比 pip 快 10-100 倍）
- ✅ 依赖版本锁定（`uv.lock` 文件）
- ✅ 环境一致性

## 安装依赖

```bash
# 安装所有依赖（包括开发依赖）
uv sync --dev

# 只安装生产依赖
uv sync

# 添加新依赖
uv add package-name

# 更新依赖
uv sync --upgrade
```

## 注意事项

1. **GPU 支持**：如果使用 GPU 训练，确保安装了对应版本的 CUDA 和 cuDNN
2. **OpenCV**：某些功能可能需要额外安装 `opencv-contrib-python`
3. **Plotly**：交互式可视化需要浏览器支持
4. **WandB**：需要注册账号（免费版足够使用）
